## 🚀 What I'm working on

I work on the backend of **[MessageOS](https://messageos.io)**, a platform where businesses run WhatsApp marketing, support and automation from one place.

- 🧱 **Multi-tenant PostgreSQL** — each business's data kept cleanly separated
- 📨 **Message pipeline** — BullMQ and Kafka workers feeding a WebSocket live inbox
- 💬 **WhatsApp Cloud API** — campaigns, templates, bot flows and embedded signup
- 🤖 **AI agents** — chatbots that answer from a pgvector knowledge base
- 🔌 **Integrations** — Shopify, WooCommerce, Zoho, Razorpay, SAP and Google Sheets
